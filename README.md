# Lexo AI 🤖

Lexo AI is a full-stack AI chatbot application built using the MERN stack. It provides a ChatGPT-style interface where users can interact with an AI model through a clean and responsive web application.

🔗 Live: https://lexoai-chatbot-t03w.onrender.com/  

## ✨ Features

- AI-powered chat interface
- Real-time conversation experience
- Markdown and formatted AI responses
- Syntax highlighting for code responses
- Chat history management
- Responsive React frontend
- REST API-based backend
- MongoDB database integration

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, CSS, React Markdown, Highlight.js  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**AI:** Generative AI API  
**Tools:** Git, GitHub

## ⚙️ Setup

### 1. Clone the repository

```bash
git clone <https://github.com/LatikaMadankar/LexoAI-ChatBot>
```

### 2. Install dependencies

```bash
cd Backend
npm install

cd Frontend
npm install
```

### 3. Configure environment variables

Create a `.env` file in the Backend folder and add the required database and AI API credentials.

### 4. Run the application

Start the backend:

```bash
npm start
```

Start the frontend:

```bash
npm run dev
```

Open the local frontend URL shown in the terminal.
